# 過去見積の種データ（架空）

`past_quotes_seed.csv` は、まだ実際の見積履歴がないため、評価を終えたゴールデンデータの部品から作った **架空の過去見積** です（2,084件）。顧客名・図番・金額はすべて架空です。生成は `python scripts/build_past_quotes.py`（決定的。何度作っても同じ）。

## 元にした部品

| データ | 部品数 | 条件の決め方 |
|---|---:|---|
| golden_v2（STEP開発用） | 508 | ランダム（顧客ごとの材質の傾向あり） |
| holdout_v1（STEPホールドアウト） | 200 | 同上 |
| dxf_v1・dxf_holdout_v1（DXF） | 200 + 100 | 同上 |
| pdf_v1・pdf_holdout_v1（図面PDF） | 300 + 200 | 図面に書かれた条件（材質・数量・表面処理・追加加工・特急・図番）をそのまま使う |

`pdf_holdout_s33_v1` と判定用の語彙ずらしは使っていません（最終判定用に残しています）。

## 作りの特徴

- **架空の顧客10社**。顧客ごとに図番の付け方・材質の傾向・値付けの水準が違う
- **リピート**：373の図番が2〜4回見積もられている。数量違い・改訂（表面処理の変更、加工の追加）・特急の有無が混じる
- **表記は人が入力したまま**：材質「SPCC」「冷延」「ボンデ」「SUS」「AL」、表面処理「ユニクロ」「粉体 黒」、追加加工「M4タップ×4、圧入ナット×2」など。「SUS」「SS」のように系統しか分からないものもある。表面処理の空欄は「なし」か「記録なし」か区別できない（実データでもよくある）
- **形状の数値がない行が約37%**（紙の図面から見積もったもの）。展開面積・切断長・穴数・曲げ数・展開寸法・形状区分が空欄
- **金額**：今のマスターと見積計算で出した標準の単価に、顧客ごとの水準、部品ごとの見積担当の判断（リピートでも同じ）、見積日の価格水準（2023年初めは今より約1割安い）、小さなばらつきを掛け、10円単位に丸めた
- **結果**：受注・失注・未回答。標準より高く出したものほど失注しやすい
- **マスターにない材質・処理・加工**も一部含む（SUS430、クロムめっき、バーリングタップなど）

## 列

見積番号、見積日、顧客名、図番、改訂、品名、材質、板厚、数量、表面処理、追加加工、特急（○）、単価、金額、結果、担当者、備考、展開面積_mm2、切断長_mm、穴数、曲げ数、展開寸法_mm、形状区分、出典

`出典` は元にした部品（例 `pdf_v1:Lv0_0018`）。**試験と検証のための列で、類似見積の検索・表示のロジックでは使わない**（実データにはない列）。
