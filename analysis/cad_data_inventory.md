## 取得可否と見積への対応

| 項目 | 取得 | 見積への利用 | 判断 |
|---|---|---|---|
| Bounding Box X/Y/Z | 可 | 画面表示、将来のブランク材計算 | OpenCASCADEから安定取得 |
| Volume | 可 | 重量・材料費、疑似加工工数 | 全候補で正値を取得 |
| Surface Area | 可 | 画面表示、将来の表面処理量 | 全候補で正値を取得 |
| Face / Edge / Vertex数 | 可 | 複雑度補助 | 全候補で取得 |
| 円筒面・半径 | 可 | 参考表示のみ | 内穴/外径/フィレットの厳密分類は未実装 |
| ポケット / 溝 | 不安定 | 使用しない | 面の隣接・開口方向を含むFeature Recognitionが必要 |
| 除去体積 | 未実装 | 使用しない | 素材ブランクの定義が必要 |
| 材質PMI | 初期実装では未使用 | CSVでユーザー選択 | CADベンダー間差を避ける |
| 公差 / 表面粗さPMI | 初期実装では未使用 | チャット補正候補 | AP242 PMIの意味解析が別途必要 |

## 採用シナリオ

STC-06を3軸CNC切削部品に見立てる。見積の中核は、安定取得できた体積とTopologyから算出する材料費・基本加工費とする。円筒面由来の候補数は参考表示に限定し、自動穴加工費には使わない。

チャット補正では、CAD Geometryだけでは判断できない皿もみ、バフ、研磨、材料、製作数量を扱う。追加工程の金額は必ずCSVマスタから引き、LLMは価格を生成しない。

## 変更理由

仕様書の暫定案にあった自動「穴加工」は採用しない。円筒面は取得可能でも、外径面・フィレット・段付き穴・同軸面の統合には追加ロジックが必要で、候補数が28〜157と過大だったためである。代わりに、体積・面数・Bounding Boxという再現性の高いGeometryを初期見積の主根拠にした。
