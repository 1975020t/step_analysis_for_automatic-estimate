# ストレステスト（stress_v1）：作り方を変えたデータでの評価

2026-09-27。golden_v1・holdout_v1 と追加検証（seed=3・4）は、同じ生成手順（`golden/sampler.py`）でシードだけを変えたデータだった。解析ロジックがこの生成手順の癖に依存していないかを確かめるため、作り方を変えたデータを別に生成して評価した。**結果の評価までが目的で、解析ロジックは修正していない。**

## 生成方法

`golden/stress.py`（生成）と `scripts/generate_stress.py`（出力）。凍結対象の `golden/sheetgen.py`・`golden/sampler.py` は読み込んで使うだけで、変更していない。正解値の計算は golden_v2 と同じで、展開ソリッドの体積・側面積と穴数（`golden/truth_v2.py`）から出す。解析器は使わない。

| 区分 | 変え方 | 件数 |
|---|---|---:|
| A_Lv0〜A_Lv4 | 従来の手順で作った部品（seed=21）を、ランダムな回転＋平行移動（±500 mm）で任意の姿勢に置く。面積・切断長・穴数・曲げ数は変わらないので、正解値はそのまま | 各40 |
| C1_slanted | 5〜7角形の凸多角形の底面。斜めの辺に2〜4枚のフランジ | 40 |
| C2_angles | トレーのフランジ角度を30〜150°から選び、上下の向きも混在させる。2段目も同様 | 40 |
| C3_closed | U字の両側の返しフランジの先端を突き合わせた閉じた筒。展開グラフに閉路ができる | 40 |
| C4_short | 曲げと曲げの間の平坦部が0.5t〜2tと短い段曲げ（ジョグ） | 40 |
| C5_side | フランジの横の辺に付くフランジ（曲げ軸が直交） | 40 |
| C6_bigflange | 底面よりずっと大きいフランジ（最大の平面が底面ではない） | 40 |
| C7_many | 長方形トレーの4辺にフランジを付け、最大3段まで重ねる（曲げが多い） | 40 |

C3 は、展開すると離れている2本の辺が、3Dでは1つの面に融合している。このため3D形状からは、正解値（展開図の切断長）をそのまま再現できない。正しい振る舞いは、値を確定させずに「概算」を示すことである。

再現手順：

```
python scripts/generate_stress.py --per-level 40 --seed 21 --out stress_data
python scripts/evaluate_golden.py --data stress_data --tolerance 0.10 --gate \
    --gate-levels A_Lv0 A_Lv1 A_Lv2 A_Lv3 A_Lv4 C1_slanted C2_angles C3_closed C4_short C5_side C6_bigflange C7_many \
    --report analysis/stress_eval.md
```

## 見つかったこと

### 1. 曲げリリーフの溝幅が板厚と同じだと表裏ペアと誤認する（A_Lv2_0001）

- 回転前の同じ部品でも同じく解析不可になったので、姿勢には依存しない
- 板厚4.5 mmのトレーで、曲げリリーフの切欠き（幅＝板厚、`sampler._tray` の `rw = max(t, 1.0)`）の両側の壁が、約4.42 mm離れて向かい合っている
- 面積比と中心位置の条件も満たしたため、この2枚が板の表裏ペアとして対応付けられた
- その結果「曲げRのない鋭い折れ」と判定され、`BEND_UNDETERMINED` で解析不可になった
- 安全側の失敗（金額が出ない）だが、従来の生成手順でも起こりうる。seed=1〜4（ホールドアウトを含む計2,708件）では発生しなかった
- 改善案：表裏ペアの判定に「両面の間に材料がある」ことに加えて、面の形や大きさが板厚方向に投影して重なることを求める

### 2. 折り返したフランジが他のパネルに接触した形状（C2_angles_0007、0022）

- 鋭角・鈍角のフランジと2段目の組み合わせで、フランジが隣接していないパネルに接触していた
- 生成器が作ったパネルどうしの距離は0で、3Dでは融合して1つのソリッドになっている
- 生成器の整合性検査（折り曲げ前後の体積一致）は、重なりは検出できるが接触は検出できない
- 実際の部品としては不正な形（1枚の板から曲げて作れない）で、解析器は鋭い折れとして解析不可（`BEND_UNDETERMINED`）にした。**解析器の不具合ではなく、ストレス生成器の検査漏れ**

### 3. 閉じた筒（C3_closed、40件）

- 経路間の位置ずれの検査（閉路では、2つの経路で同じ面にたどり着いた位置を比べる）が、全件で158〜341 mm程度のずれを検出した。全件が `FLAT_PATTERN_UNVERIFIED` で「概算」となり、危険誤答はなかった
- ただし返した値は大きく外れている
  - 面積：誤差は −96%〜−102%（ほぼ0、負の値もある）
  - 切断長：誤差は −13%〜−43%
  - 穴数：一致0%
- 展開図がまともに作れないまま値を返している。現状は「概算」表示に頼っているが、金額としては使えない値である
- 改善案：閉路で位置ずれが大きい場合は「解析不可」にする、または突き合わせ部を切断線として扱い、閉路を切って展開する

## まとめ

- 任意の姿勢（A）と、斜め辺・角度混在・短い平坦部・直交フランジ・大きいフランジ・多段（C1・C2・C4〜C7）の新しい形は、ほぼすべて正しく解析できた。汎用展開は生成手順の癖（座標軸に沿った底面、最大面＝底面など）に依存していない
- 失敗はすべて安全側だった（解析不可、または概算表示）
- 修正候補は次の2件（今回は未対応）
  - 板厚と同じ幅の溝の誤ペア
  - 閉路形状で意味のない値を返すこと
- 生成器の課題：C2 のような接触（パネルどうしが触れる）を検出する検査がない。従来の `sheetgen` の整合性検査も同じで、ストレス生成器では今後、パネル間距離の検査を加えるとよい
