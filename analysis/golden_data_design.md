# 板金ゴールデンデータの設計と初回評価

実部品のGolden Dataがまだないため、正解値を持つ板金部品をパラメトリックに生成し、解析ロジックの対応範囲と精度を定量評価する。

## 生成方法

`golden/sheetgen.py` は部品を「展開図の底面ポリゴン＋フランジの木構造＋穴・切欠き」で定義し、同じ定義から3つを出力する。

| ファイル | 内容 |
|---|---|
| `<name>.step` | 曲げ後の3D形状（解析器への入力）。曲げ部は正確な円筒扇形、穴は真円の円筒面 |
| `<name>_unfolded.step` | 展開形状。曲げ部の長さは曲げ代 BA = θ(R + K·t) |
| `<name>_truth.json` | 正解値：展開面積、切断長、穴数、曲げ数、板厚、各曲げの角度・内R・向き・曲げ代 |

正解値は展開ソリッドから算出する（面積＝体積÷板厚、切断長＝側面積÷板厚、穴数＝展開図の内側ループ数）。テスト対象の解析器には一切依存しない。

生成器自身の整合性として、各部品について次を確認し、満たさないもの（折り曲げ時にフランジが衝突する、展開時に重なる等）は破棄して再サンプリングする。

- 曲げ後・展開のB-Repが有効、曲げ後が単一Solid、展開図が単一ポリゴン
- 曲げ後の体積＝展開の体積（K=0.5では中立面長が保存されるため厳密に一致する）
- 展開ソリッドから求めた面積＝2Dレイアウトから求めた面積

さらにテストで、L字＋穴の手計算値と一致すること、同じシードで同じ部品が生成されることを確認している。

## 複雑度レベル

| レベル | 形状 | 主なパラメータ範囲 |
|---|---|---|
| Lv0 | 平板：丸穴、長穴、角穴（傾き含む）、外周切欠き、角落とし | 40〜300 × 30〜200 mm、穴1〜10個 |
| Lv1 | 平行曲げのみ：L、U、Z、ハット、多段チェーン（上下混在） | 曲げ1〜4、角度90°主体＋30/45/60/120/135° |
| Lv2 | 底面＋1段フランジ（2〜4辺）、部分幅フランジ、曲げリリーフ | フランジ長 6t〜60 mm |
| Lv3 | Lv2＋フランジ上のフランジ（返し・段付き）を深さ3まで | 曲げ3〜10 |
| Lv4 | ヘム（180°曲げ、オープンヘム）。展開したうえで **ヘムとして報告する**（2026-09-27 に「弾く対象」から変更） | 内R 0.5t〜1t |

共通：板厚 0.8〜4.5 mm（0.8/1.0/1.2/1.6/2.0/2.3/3.2/4.5）、内R 0.5t〜2t、K=0.5。

加えて、形状を手で定義した8件（`golden/curated.py`、G01〜G08）を各レベルに含める。

## 使い方

```
python scripts/generate_golden.py --per-level 100 --seed 1 --out golden_data   # 約1分
python scripts/evaluate_golden.py --data golden_data --report analysis/golden_eval_baseline.md   # 約2分
python scripts/render_golden.py --data golden_data --per-level 2 --out analysis/golden_contact_sheet.png
```

生成データ（`golden_data/`）はGit管理外。シードと件数が同じなら同一データが再生成される。部品ごとの結果は `golden_data/results.csv` に出力される。

## 初回評価（2026-09-27、現行ロジック）

数値は [golden_eval_baseline.md](golden_eval_baseline.md) を参照。要点は以下のとおり。

1. **Lv0（平板）は全件正解。** 面積・切断長・穴数とも誤差なし。
2. **Lv1（平行曲げ）は面積・切断長が全件正確だが、確定で正解は0%。** 曲げ部品は穴数の信頼度が常に medium で、見積が必ず「概算」になる。さらに穴数の一致は44%にとどまる。不一致57件はすべて長穴・角穴を含む部品での過大カウントで、丸穴だけの部品は全件一致した（コード上、曲げ部品では円筒面を1面ずつ穴として数えるため、長穴の両端の半円筒が別々に数えられる）。
3. **Lv2・Lv3は危険誤答が6割超。** トレー展開がフランジを矩形とみなし、2段目以降のフランジを無視するため、面積が最大40%、切断長が最大46%小さいまま「確定値」として出る。
4. **Lv4（ヘム）**：当初は「弾く対象」として評価し、1件も弾けていなかった。その後、方針を「解析対象」に変更し、誤差±10%で再評価したところ、面積・切断長の誤差は0%、ヘムの検出も100%で、不合格は穴数の数え方だけが原因だった（[golden_eval_baseline_10pct.md](golden_eval_baseline_10pct.md)）。
5. **曲げ数は全レベルで100%一致。** 板厚も全件許容誤差内。認識部分は安定しており、問題は展開と穴の数え方に集中している。

## 限界

- すべて理想的なCADモデル。実際のCAD（SolidWorks、iCAD、Fusion等）が出力するSTEPの癖（面の分割、微小面、公差のずれ）は含まない。実部品やCADで作成したサンプルで補う必要がある。
- K=0.5固定。K≠0.5の展開は生成できるが、体積一致による自己検証が使えなくなる。
- 成形加工（ルーバー、エンボス、バーリング、タップ）、圧入部品、曲げを横切る穴は未対応。
- 形状パラメータの分布は想定であり、実際の受注部品の分布を反映していない。
