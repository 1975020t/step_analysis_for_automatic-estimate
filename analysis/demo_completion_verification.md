# デモ完成条件 検証記録

要件定義「STEP板金解析デモ 要件定義」14節の11項目に対する第一版の検証記録。

| # | 完成条件 | 実装・検証 | 状態 |
|---:|---|---|---|
| 1 | STEPファイルを入力できる | Streamlit file_uploader が .step / .stp を受け付ける。test_initial_ui_has_step_input_and_analyze_action で入力部品と実行ボタンを確認。 | 達成 |
| 2 | 対象となる単一板金部品を解析できる | CadQueryで単一Solidを読み、一定板厚・板金寸法比・表裏面整合を検証。平板とR曲げのSTEP再読込テストが成功。 | 達成 |
| 3 | 板厚を返せる | 対向平面距離を面積支持で選び、全表裏面と体積で検証。平板2.0 mm、R曲げ2.0 mmを誤差1%以内でテスト。 | 達成 |
| 4 | 曲げ回数を返せる | 対応する内外円筒面を軸位置で統合。R曲げ1回、平板0回をテスト。曖昧な鋭角折れは解析不可。 | 達成 |
| 5 | 曲げる前の平らな形状を求められる | 中立面領域と外周・内周境界からなる面積保存の計量展開表現 FlatPatternSummary を生成。R曲げの理論展開値で検証。 | 達成 |
| 6 | 展開面積を返せる | 一定板厚Solidの体積÷板厚と表裏面中央面積を照合して返す。穴付き平板とR曲げで理論値を検証。 | 達成 |
| 7 | 切断長を返せる | 表裏面以外の切断面積÷板厚で外周＋穴周囲を取得。穴付き平板とR曲げで理論値を検証。 | 達成 |
| 8 | 穴数を返せる | 切断面の接続成分から最大外周成分を除いた閉じた内周を数える。丸穴＋角穴=2を検証。 | 達成 |
| 9 | 5項目をまとめて確認できる | 成功画面の5つのメトリクスを test_success_ui_shows_all_five_results_together で確認。 | 達成 |
| 10 | 対象外のSTEPに解析不可を返せる | 複数Solid、非板金ブロック、段付き板厚、曲げ判定不能を unsupported としてテスト。返却数値は null。 | 達成 |
| 11 | 解析失敗の原因をある程度確認できる | 理由コード・日本語メッセージ・段階別状態を返し、UI表示をテスト。成功時も表裏面、曲げ軸、穴面を表示。 | 達成 |

検証コマンド:

    .venv\Scripts\python.exe -m pytest -q
    .venv\Scripts\python.exe -m compileall -q app.py src tests
